# SimpleBank Practice Project

A beginner-friendly banking UI for practicing HTML5, CSS3, Bootstrap, JavaScript, validation, localStorage and later Selenium/Playwright automation.

## Run
Open `login.html` directly, or preferably use VS Code Live Server.

Login:
- Username: `admin`
- Password: `admin123`

## Features
- Login validation
- Checking and savings balances
- Balance transfer with validation
- Recent transaction history
- Search and filter transactions
- Add/remove beneficiaries
- Deposit and withdrawal simulation
- LocalStorage persistence
- Logout

## Automation ideas
Test successful/failed login, required fields, same-account transfer, zero/negative transfer, insufficient funds, successful transfer, updated balance, transaction search/filter, beneficiary validation, and logout.

## Next learning step
Replace local mock data with AJAX/fetch calls to REST endpoints, then connect those endpoints to Java microservices and a database.
